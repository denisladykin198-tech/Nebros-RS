# Nebros RS

**Советский аналоговый синтезатор**

Виртуальный аналоговый синтезатор, вдохновлённый переносным электромузыкальным синтезатором «Поливокс» и советской звукотехникой. Написан на Rust с использованием `egui` для GUI и `cpal` для аудио.

---

## Особенности

### Синтез

- **4 осциллятора** с независимой настройкой:
  - Формы волн: пила, меандр, треугольник
  - Регулировка громкости, детюна (±100 центов) и октавы (±2)
  - Визуальное превью формы волны

- **Фильтр низких частот** (state-variable):
  - Частота среза: 20 Гц — 8 кГц
  - Резонанс с самовозбуждением
  - Модуляция от огибающей (Env → Cutoff)
  - Keyboard Tracking
  - Визуализация АЧХ

- **ADSR-огибающая**:
  - Attack: 1 мс — 5 с
  - Decay: 1 мс — 5 с
  - Sustain: 0 — 100%
  - Release: 50 мс — 30 с
  - Графическое превью огибающей

- **4 режима голосоведения**:
  - **Монофония** — классический моно-синт
  - **Легато** — плавный переход без ретриггера
  - **Полифония** — 8 голосов с voice stealing
  - **Портаменто** — плавное скольжение между нотами

### Пружинный ревербератор

Полноценная эмуляция пружинного реверба с 13 параметрами:

| Параметр | Описание |
|----------|----------|
| Mix | Соотношение сухого/влажного сигнала |
| Decay | Время затухания (0.1 — 10 с) |
| Damping | Демпфирование высоких частот |
| Pre-Delay | Предзадержка (0 — 200 мс) |
| Room Size | Размер «комнаты» (0.5 — 3x) |
| Diffusion | Диффузия (аллпасс-фильтры) |
| Brightness | Яркость (HPF + LPF) |
| Modulation | Модуляция (Wow/Flutter) |
| Stereo Width | Стерео-ширина (до 1.5x) |
| Spring Noise | Шум пружин |
| Spring Tension | Натяжение пружин |
| Metal Fatigue | Усталость металла |
| Rust Level | Уровень ржавчины |

### Артефакты и винтажность

Синтезатор эмулирует неидеальности советской аналоговой техники:

- **Температурный дрейф** — расстройка при нагреве (15°C — 60°C)
- **Шум питания** — фон 50 Гц с гармониками (100, 150, 250 Гц)
- **Просадка напряжения** (Voltage Sag) — кратковременное падение уровня
- **Старение компонентов** — дребезг, треск, ухудшение параметров
- **Импульсные помехи** — редкие щелчки и клики

### Дополнительно

- **Быстрые пресеты**: Моно-лид, Поли-пэд, Басс, Скрипки
- **Экранная клавиатура** с подсветкой активных нот
- **Статус-панель**: отображение нот, аккордов, огибающей
- **Автоматическое восстановление аудио** при ошибках
- **Отслеживание смены аудиоустройства**

## Режимы сборки

Проект поддерживает два режима компиляции:

### 1. Standalone-приложение (`gui`)

Полноценное десктопное приложение с GUI (по умолчанию).

```bash
cargo build --release
cargo run --release
```

### 2. Модуль Dansel Engine (`module`)

Синтезатор как модуль для моего другого проекта, вдохновлённого Native Instruments Reaktor, суть которого - создать плагин обёртку, что позволит загружать любой .dll файл внутри DAW

```bash
cargo build --release --features module
```

**Экспортируемый API**:
- `dansel_get_api()` — получение `ModuleApi` структуры
- `create()` / `destroy()` — создание/уничтожение экземпляра
- `prepare(sample_rate, max_block)` — инициализация
- `process_midi(events, outputs, frames)` — обработка MIDI и рендер аудио

## Установка

### Требования

- **Rust** 1.70+ ([rustup.rs](https://rustup.rs/))
- **Linux**: `libasound2-dev`, `libxkbcommon-dev`
- **Windows**: Visual Studio Build Tools
- **macOS**: Xcode Command Line Tools

### Сборка

```bash
# Клонирование
git clone https://github.com/yourusername/nebros-rs.git
cd nebros-rs

# Debug-сборка
cargo build

# Release-сборка (оптимизированная)
cargo build --release

# Запуск
cargo run --release
```

### Linux (Ubuntu/Debian)

```bash
sudo apt install libasound2-dev libxkbcommon-dev libgl1-mesa-dev
cargo build --release
```

## Технические детали

### Аудио

- **Sample Rate**: определяется устройством (обычно 44100 или 48000 Гц)
- **Формат**: F32 stereo
- **Буферизация**: определяется CPAL
- **Нормализация**: `output * 0.3`, soft-clip через `tanh`

### Производительность

- **Рендеринг**: один сэмпл за вызов `synth.process(dt)`
- **Полифония**: до 8 голосов
- **GUI**: 60 FPS (`request_repaint_after(16ms)`)
- **RNG**: `SmallRng` с фиксированным seed (детерминированность)

### Безопасность

- Защита от денормализации (`DENORMAL_FLT = 1e-15`)
- Защита от взрывного `tan()` в фильтре (clamp ниже Найквиста)
- Безопасная дробная задержка в ревербе (проверка границ буфера)
- Soft-clip на выходе реверба

---

## Известные ограничения

- Только F32-формат аудио (нет I16/I24)
- Нет сохранения/загрузки пресетов в файл
- Эффекты кроме реверба — заглушки
- Нет MIDI-входа в GUI-режиме (только экранная клавиатура)
- Dansel Engine модуль не имеет встроенного редактора
